# ET574 Homework 4 - Dice Game Simulator

## Description
This project is a two-dice game simulator created using Python.
The program rolls two six-sided dice and evaluates the total.

## Game Rules
- 7 or 11: Win
- 2, 3, or 12: Lose
- 4, 5, 6, 8, 9, or 10: Roll Again

## Files
- main.py: Contains the Die class, DiceGame class, and main menu.
- test_dicegame.py: Contains unit tests for the program.
- README.md: Provides project information and documentation.

## How to Run
Run the game with:

python main.py

Run the unit tests with:

python -m unittest -v
